## P2 — Shared deterministic engine and verified scores

Completed: moved the six game paths to a shared seeded 20 Hz engine used by the browser and Worker. Ranked starts pin game ID, starting level, starting speed, seed, and rules version in D1. The browser sends action/tick logs only after a true terminal state. Reset abandons a ranked run. The Worker checks owner, time budget, event order, terminal state, and replay bounds, then calculates raw and final scores itself. Casual play remains available when ranked is unavailable and is explicitly marked as unranked in the UI.

Files: `src/engine/`, gameplay classes in `src/games/`, input and panel integration in `src/control/` and `src/components/*panel/`, `worker/src/runs.ts`.

Checks: 38 focused engine tests cover all six deterministic starts, multiple seeds and levels, terminal traces, chosen speed, manipulated logs, Tetris line-bonus regression, exact 12,000-tick terminal traces, and optimized replay/client-state equivalence. Worker integration submits a real Snake terminal trace and confirms that starting level 5 multiplies the server-computed raw score by 5; concurrent finish requests return the same stored result. Replay verification now skips per-tick JSON copies and action-free paused spans without changing the public immutable game step or anti-cheat bounds. After optimization, local Node median Tank replay measured about 9 ms for a natural terminal game, 8 ms for a legal 12,000-tick pause-padded trace, and 42 ms for 12,000 active steps across successive sessions. These are local wall times, not Cloudflare billed CPU.

Cloudflare CPU check: a temporary, secret-protected Worker ran legal 12,000-tick pause-padded verification and 12,000-active-step stress cases for all six games. All 12 calls succeeded. Time-correlated Analytics groups reported zero errors and CPU p99 values up to about 278 ms, far below the production 5,000 ms cap on the user-confirmed Workers Paid plan. The temporary CPU Worker was deleted after measurement. More varied human gameplay and load testing remain useful. Rules version 1 intentionally changes Tetris to clear lines immediately, keeps the chosen starting speed as a floor, and fixes 1–4 line bonuses to 100/300/700/1500; the old four-line path could produce `NaN`.

## P5 — Hardening and deployment

Completed: frontend tests, Worker integration, TypeScript typecheck, lint, production build, local and remote D1 migrations, Worker runtime/browser smoke, Wrangler deploy dry-run, isolated Cloudflare Preview, and ranked production rollout. A static `public/_headers` file applies CSP, frame, referrer, and permissions restrictions to the Worker-served assets. WebSocket upgrades are rate-limited; the Hub caps 20 active connections per edge IP, throttles each socket's manual sync requests, and closes invalid/oversized messages. An hourly bounded cleanup purges up to 1,000 unreferenced verified runs and 1,000 old sessions per invocation after 90 days while preserving current Top 10 rows; migration `0003_retention_indexes.sql` supports it. `.dev.vars` and local test artifacts are gitignored; the production secret remains only in Cloudflare. The Preview, its D1, and the separate CPU probe Worker were deleted after testing.
